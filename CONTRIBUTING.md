# Contributing to Nations RTS / Cómo aportar

Nations RTS is a game built with AI. You are welcome to improve it with yours:
Claude, Codex, Gemini, Copilot, a local model or your own hands.

Nations RTS es un juego hecho con IA. Puedes mejorarlo con la tuya: Claude,
Codex, Gemini, Copilot, un modelo local o tus propias manos.

## How / Cómo

1. Fork the repository and create a branch. / Haz un *fork* y una rama.
2. Point your AI at `AGENTS.md` first: it explains how the game is built, the
   code style and how to test. / Dale a tu IA primero `AGENTS.md`: explica
   cómo está hecho el juego, el estilo del código y cómo probar.
3. Keep each pull request small and about one thing. Say what you changed, why,
   and how you tested it (screenshots for anything visual). / Cada *pull
   request*, pequeño y de una sola cosa: qué cambiaste, por qué y cómo lo
   probaste (capturas si se ve).
4. Look for issues labeled `good first issue` or `ai-friendly`. / Busca las
   tareas marcadas `good first issue` o `ai-friendly`.

## Rules / Reglas

- Only add art, sounds or code you are allowed to share: your own, or CC0,
  CC-BY (credited), SIL OFL, MIT. Never paid packs or files from other games.
  List the source and license in the `LICENCIAS.md` of that folder. / Solo
  recursos que se puedan compartir: propios, CC0, CC-BY (con crédito), SIL OFL
  o MIT. Nunca packs de pago ni archivos de otros juegos. Apunta fuente y
  licencia en el `LICENCIAS.md` de la carpeta.
- No secrets, keys or personal data. / Nada de claves ni datos personales.
- The owner (el dueño) decides what goes in and the direction of the game
  (`VISION.md`). / El dueño (el dueño) decide qué entra y hacia dónde va el
  juego (`VISION.md`).
